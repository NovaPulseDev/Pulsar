### **OVERVIEW**
This is my Quickshell + Hyprland configuration, based on the Dynamic Island. Sometimes, Hyprland rice has to look minimal but it has to show you a lot, so all of the modules live inside the Dynamic Island. The app launcher, the theme picker, the wallpaper picker, the control center, all of it. It's minimal and it's small, but it will serve you. The colors are autogenerated with Matugen, with templates for Hyprlock, Hyprland, GTK, Kitty, NeoVim, Quickshell and VSCode/VSCodium. Then, we have the fastfetch. Minimal, but does the job. Fish + Starship gives you a sleek and unique prompt. Hyprland, preconfigured with the keybinds. I hope you enjoy this Dynamic island based rice.

### **INSTALLATION**

Note: The two installation methods **ONLY WORK ON ARCH LINUX AND ONLY ON HYPRLAND.** This is a choice.

Now there are two ways that you can do this, the online installer way or the git clone / local install way.

### *Online install*

For the online install, just copy / type this into the shell.
```bash
curl -fsSL https://is.gd/pulsarqs | bash
```
### *Local install*

For the local install, you will need git.

First, install git.
```pacman
sudo pacman -S --needed git
```

Then clone the repo.
```git
git clone https://github.com/lunardagger420/quickshell-hypr-rice.git --depth=1
```

Finally, cd into the folder and run the installer.
```cd
cd ~/quickshell-hypr-rice && ./install.sh
```
